### 🌤️ SkyCast — Previsão do Tempo
> Consome a **API REST da OpenWeatherMap** para exibir dados climáticos em tempo real de qualquer cidade do mundo.

**Funcionalidades:**
- 📍 Geolocalização automática via `navigator.geolocation`
- 📅 Previsão dos próximos 5 dias com filtro de horário
- 🌙 Modo claro/escuro com variáveis CSS e `localStorage`
- 📱 Layout 100% responsivo

**[🔗 Ver projeto ao vivo](https://sky-cast-blush.vercel.app/)** | **[📂 Ver código](https://github.com/gaprelino/skycast)**

---

### 🎬 CineSearch — Buscador de Filmes
> Consome a **API REST do TMDB** para buscar filmes com filtros, paginação dinâmica e sistema de favoritos.

**Funcionalidades:**
- ❤️ Sistema de favoritos persistido com `localStorage`
- 📄 Paginação dinâmica com range inteligente
- 🌙 Modo claro/escuro temático
- 🌍 Resultados em português (pt-BR)
- 📱 Layout 100% responsivo

**[🔗 Ver projeto ao vivo](https://cine-search-rho.vercel.app/)** | **[📂 Ver código](https://github.com/gaprelino/cinesearch)**
